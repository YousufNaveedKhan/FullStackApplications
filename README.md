# FullStackApplications

A practical learning repository for building web applications using modern JavaScript technologies.

## About

This repository documents a hands-on course in full-stack web development. It is built up gradually, lecture by lecture, starting from backend fundamentals and expanding toward complete full-stack applications. Students studied MongoDB fundamentals separately before this course began; that material is not duplicated here.

## Technologies

Technologies are introduced progressively as the course advances, not all at once. So far the course has covered:

* Node.js
* Express.js
* MongoDB (integration with Node.js/Express)
* REST APIs

Topics such as Postman, authentication, and React.js will be introduced in later lectures as the course progresses.

## Lectures

Each `LectureXX/` folder contains the code and exercises created during that specific class. Lectures are organized sequentially, and folders are added as new classes take place. Code in earlier lectures is kept simple and reflects what had been taught up to that point, so patterns may look basic compared to later lectures.

## Projects

Complete, larger student projects will be added to the repository as the course progresses.

## Learning Approach

Concepts are learned through practical implementation rather than theory alone — building APIs, integrating databases, testing endpoints, and eventually connecting a frontend to build complete full-stack applications.

---

This course and repository are continuously evolving. The structure and topics above reflect current progress, not a fixed curriculum.
